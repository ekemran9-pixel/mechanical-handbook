Safety & relief valves

PSV types, terms, set pressure, blowdown, bench testing, overhaul and handling rules.

On this page
  1. Terms
  2. Types
  3. Bench test procedure
  4. Handling and installation
  5. Inspection interval

Terms

  • Set pressure: pressure at which the valve starts to open.
  • Overpressure: pressure rise above set to reach full lift (often 10%).
  • Accumulation: pressure rise above MAWP during discharge (10% for single valve, 16% multiple valves, 21% fire case per ASME VIII).
  • Blowdown: difference between set and reseat pressure, typically 7–10% (steam 2–6%).
  • CDTP (cold differential test pressure): bench set pressure corrected for back pressure and temperature.
  • Simmer: audible leakage just below set (compressible fluids).
  • Chatter: rapid opening and closing. Destroys seats. Caused by oversizing, inlet losses above 3% of set, or high built-up back pressure.

Types

  • Safety valve: pops open fully. Steam, gas, vapour.
  • Relief valve: opens in proportion to overpressure. Liquids.
  • Safety relief valve: either service.
  • Conventional spring loaded: back pressure affects set pressure.
  • Balanced bellows: bellows cancels back pressure effect. The bonnet vent must be open to atmosphere (leakage there = failed bellows).
  • Pilot operated: main valve held shut by system pressure via pilot. Tight up to near set. Clean service.

Bench test procedure

  1. Record as-received: pop the valve before cleaning to find the "as found" set pressure. This shows whether it would have protected the equipment.
  2. Strip, clean, inspect: nozzle, disc, guide, spring, bellows, stem.
  3. Lap disc and nozzle seats flat (optical flat to check: max 2–3 light bands).
  4. Reassemble, set the spring adjusting screw to approximately set.
  5. Test on a test bench with the right medium (air/nitrogen for gas, water for liquid, steam for steam valves where required).
  6. Adjust to CDTP. Confirm set pressure repeats (e.g. 3 consecutive pops within ±3% for set below 70 psi, or ±2 psi; ±3% above).
  7. Seat tightness test to API 527: at 90% of set, count bubbles per minute through a tube 6 mm below water. E.g. 40 bubbles/min allowed for orifice F and smaller at set up to 1000 psi.
  8. Fit seal wire with tag: set pressure, date, shop, valve tag number.

Handling and installation

  • Carry and store upright. Rough handling shifts set pressure.
  • Keep inlet and outlet capped until fitted.
  • Inlet pipe pressure drop < 3% of set pressure. No block valve unless locked open with a car seal (CSO) under a permit system.
  • Outlet pipe supported, no load on the valve body. Drain the discharge line low points.
  • Don't use the lifting lever unless the system pressure is at least 75% of set.
  • Never gag a PSV on an operating system.

Inspection interval

Typically 2–5 years, based on service and history (clean service longer, fouling or corrosive service shorter). Use as-found results to adjust the interval.
